# Stremio Server WebAdmin 3.0.12

## Summary

3.0.12 makes the BitTorrent listen port runtime-driven and read-only in WebAdmin. DIRECT mode and VPN providers without port forwarding use the safe default 6881; when a supported provider publishes a forwarded port, the Core can follow it live without restarting the Stremio server.

## Components

- Platform / WebAdmin: **3.0.12**
- Core: **1.6.34**
- VPN Gateway: **3.0.12**
- Default BitTorrent listen port: **6881**
- `Bt Listen Port` is locked in WebAdmin and displays the effective runtime listener.
- `/netcheck.json` exposes `listenPortMode` and `configuredDefaultPort`.
- Missing or invalid provider forwarding state falls back to 6881.
- VPN profile/direct transitions clear stale forwarded-port state.
- CyberGhost remains correctly treated as a provider without VPN port forwarding; outbound P2P is unchanged.

## Upgrade notes

Use the normal documented upgrade procedure and preserve the existing `.env` and persistent volumes. The BitTorrent listen port no longer requires manual editing in WebAdmin. DIRECT mode and VPN providers without forwarding continue to use 6881 automatically.
