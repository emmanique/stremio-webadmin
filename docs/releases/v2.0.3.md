# Stremio Server WebAdmin 2.0.3

## Summary

Controlled upstream integration release based on andrewhack/stremio-libtorrent-server 1.6.14 while preserving the fork-owned WebAdmin, single-Compose VPN/Pi-hole topology, persistent configuration and VAAPI runtime policy.

## Components

- Fork platform: 2.0.3
- Upstream server/core: 1.6.14
- WebAdmin: 2.0.3
- VPN gateway: 2.0.3
- Upstream baseline: 1.6.14 (53efb275)

## Upstream changes integrated

- Library playback/file-selection fixes through upstream 1.6.14.
- Additional streamed video types in Library.
- ffprobe timeout handling improvements.
- HLS/subtitle and stream file-serving fixes.
- Pin and Library state fixes.
- Certificate reuse/validation improvements where compatible with the fork runtime.
- Upstream regression tests for the imported core paths.

## Fork protections retained

- Single compose.yaml runtime.
- DIRECT/VPN operation with Gluetun and Pi-hole.
- Persistent WebAdmin configuration and coordinated save/restart.
- Existing Docker volume identities.
- BitTorrent port 6881 TCP/UDP.
- VAAPI policy and /dev/dri/renderD128 support.
- Fork-specific Library metadata/presentation integration.

## Validation required before release

- Full deterministic and integration test suites.
- Compose DIRECT/VPN validation.
- WebAdmin save/restart persistence.
- VPN DNS/no-bypass checks.
- VAAPI transcode regression.
- Library/pin/cache regression.
- Container image smoke tests.

## Upgrade notes

Preserve persistent Docker volumes. Do not use `docker compose down -v` during upgrade.
