# Stremio Server WebAdmin 1.6.9-server.12

## Components

- Core: `1.6.9`
- Server/Fork: `1.6.9-server.12`
- WebAdmin: `1.3.1`
- VPN gateway: `1.6.9-server.12`

## VPN DNS / Pi-hole fix

This release fixes DNS routing in CyberGhost VPN mode so Pi-hole continues to receive and log Stremio DNS queries while the Stremio runtime shares the Gluetun network namespace.

In VPN mode:

- Stremio DNS is routed to Pi-hole at `172.30.0.53`;
- Pi-hole remains the filtering and query-logging layer;
- Pi-hole upstream DNS is routed through Gluetun so upstream DNS traffic follows the VPN path;
- the VPN remains fail-closed and does not silently fall back to the normal WAN path if the tunnel is unavailable;
- WebAdmin and Pi-hole remain directly reachable from the LAN.

## CyberGhost connection manager

The existing CyberGhost profile manager remains included, with multiple OpenVPN profiles, ZIP bundle import, create/edit/activate/delete operations, startup profile selection, private credential storage, reconnect/disconnect controls and protection tests.
