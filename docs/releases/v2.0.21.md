# Stremio Server WebAdmin 2.0.21

## Summary

Patch release for the VPN status regression discovered during physical 2.0.20 upgrade validation. The integrated Stremio/libtorrent core remains 1.6.15.

## Components

- Fork platform: 2.0.21
- WebAdmin: 2.0.21
- VPN gateway: 2.0.21
- Integrated server/core: 1.6.15

## Changes

- Fixes HTTP 500 from `/api/vpn/status` introduced by the 2.0.20 active-profile provider normalization.
- Adds the missing Python `json` import required by the persisted active-profile parser.
- Keeps provider reporting aligned with the active CyberGhost profile.
- Adds regression coverage for the provider parser dependency.
- No deployment topology, persistent-volume layout, VPN credentials, or `.env` migration is required.

## Validation

- PR #59 Fast CI: passed.
- PR #59 Full regression: passed.
- Physical 2.0.20 upgrade validation confirmed all non-VPN checks before this hotfix:
  - WebAdmin 2.0.20 installed successfully;
  - Server/Core 1.6.15 healthy;
  - `max_streams=3` preserved;
  - `LIBVA_DRIVER_NAME` absent;
  - `/api/config` and runtime both reported `/dev/dri/renderD129`;
  - NVIDIA runtime remained active.
- 2.0.21 specifically addresses the VPN status endpoint regression discovered in that validation.

## Upgrade notes

1. Run `sh scripts/backup-before-upgrade.sh`.
2. Preserve the existing `.env` and Docker named volumes.
3. Extract the 2.0.21 deployment package over the existing installation directory.
4. Run `sh scripts/check-env-upgrade.sh`.
5. Run `sh start.sh config`.
6. Run `sh start.sh pull`.
7. Run `sh start.sh up -d --force-recreate`.
8. Validate `/api/vpn/status`, then test DIRECT -> VPN -> DIRECT.
9. Do not use `docker compose down -v` during a routine upgrade.
