# Stremio Server WebAdmin 1.6.9-server.11

## Components

- Core: `1.6.9`
- Server/Fork: `1.6.9-server.11`
- WebAdmin: `1.3.1`
- VPN gateway: `1.6.9-server.11`

## CyberGhost connection profiles

The VPN page now manages multiple independent CyberGhost OpenVPN connections instead of one global credential set.

Each new connection imports the CyberGhost ZIP containing `openvpn.ovpn`, `ca.crt`, `client.crt` and `client.key`, together with the generated OpenVPN username/password and optional pre-shared value.

The WebAdmin now supports:

- Create connection;
- Edit connection;
- Activate connection;
- Delete inactive connection;
- Enable/disable one startup connection;
- country and server-group display;
- OpenVPN UDP/TCP detection/validation;
- CyberGhost extra-feature metadata;
- private credential/certificate storage;
- existing Connect / Disconnect / Reconnect, protection test and redacted logs.

## Safer OpenVPN bundle handling

The importer validates ZIP paths and required files, rejects unsafe archive members, validates certificate/key material and generates a sanitized runtime OpenVPN configuration. Script/plugin/management directives are not copied into the runtime configuration.

The CyberGhost bundle controls the remote endpoint and protocol. The gateway runs Gluetun with `VPN_SERVICE_PROVIDER=custom` and the generated `OPENVPN_CUSTOM_CONFIG` so the exact CyberGhost router/device configuration can be used.

## Startup profile selection

The VPN gateway now supports persisted active/startup profile selection in `vpn-data`. One profile can be selected automatically when the VPN gateway starts. Manual activation can switch profiles while retaining the configured startup default.

## Documentation and updates

`README.md` now documents:

- new installation in one run;
- updating an older/existing Git clone;
- single-command update for direct mode;
- single-command update for VPN mode;
- package-only Compose refresh;
- the complete CyberGhost connection-profile workflow.

`VPN.md` was updated to match the new profile model and security behaviour.

## Packages

This release publishes the three fork-owned images with versioned and `latest` tags:

```text
ghcr.io/emmanique/stremio-libtorrent-server-webadmin:1.6.9-server.11
ghcr.io/emmanique/stremio-libtorrent-server-webadmin-webadmin:1.3.1
ghcr.io/emmanique/stremio-libtorrent-server-webadmin-vpn:1.6.9-server.11
```

Persistent named volumes remain compatible. Do not use `docker compose down -v` for a normal upgrade.
