# Stremio Server WebAdmin 3.0.3

## Summary

3.0.3 fixes the Stremio DNS path when the platform operates through the
persistent Gluetun network namespace. Stremio, libtorrent and child processes
now resolve through Pi-hole in both DIRECT and VPN modes.

The validated path is:

```text
Stremio / libtorrent / child processes
        |
        v
Pi-hole 172.30.0.53:53
        |
        v
Gluetun 172.30.0.10:1053
        |
        +-- DIRECT -> direct DNS upstream
        +-- VPN    -> Gluetun secure DNS -> VPN
```

## Components

- Platform/Fork: 3.0.3
- WebAdmin: 3.0.3
- VPN Gateway coordinated image: 3.0.3
- Upstream Server/Core: 1.6.20 (unchanged)
- Pi-hole: existing coordinated topology, upstream `172.30.0.10#1053`

The core server remains 1.6.20 because this release changes deployment DNS
topology, WebAdmin validation, tests and packaging rather than the Stremio core.

## DNS path and WebAdmin validation

Stremio now has a private `/etc/resolv.conf` with
`nameserver 172.30.0.53`. Sharing Gluetun's network namespace no longer means
sharing Gluetun's resolver configuration.

WebAdmin's Gluetun validation performs an end-to-end DNS check. It verifies the
Stremio resolver, generates a query through the normal system resolver, confirms
that Pi-hole observed the query from the shared namespace, and confirms Pi-hole
forwarded it to Gluetun on port 1053.

DIRECT and VPN modes are evaluated independently. VPN tunnel, public VPN IP and
kill-switch checks are required in VPN mode and are not incorrectly required
while intentional DIRECT mode is active.

## Deployment package

`docker/stremio-resolv.conf` is a required deployment input and is included in
the deployment ZIP and TAR.GZ. Regression tests protect the read-only
`/etc/resolv.conf` bind, Pi-hole upstream, and removal of the obsolete
`STREMIOSRV_DNS_SERVER` setting.

## Upgrade notes

Before upgrading, run `sh scripts/backup-before-upgrade.sh` and preserve the
existing `.env` and named Docker volumes. Extract the 3.0.3 deployment package
over the installation directory, then run:

```bash
sh scripts/check-env-upgrade.sh
sh start.sh config
sh start.sh pull
sh start.sh up -d --force-recreate
```

The new `docker/stremio-resolv.conf` file must exist beside the deployment
Compose files. Recreating the Stremio container applies its private resolver
mount. Do not use `docker compose down -v` for this upgrade.

After upgrade, validate WebAdmin's Gluetun checks in the intended DIRECT/VPN
mode and confirm the Stremio container reports `nameserver 172.30.0.53`.
