# Stremio Server WebAdmin 2.0.17

## GPU backend detection and selection

- Added explicit GPU backend selection with `auto`, Intel/VAAPI, NVIDIA/NVENC and CPU modes.
- AUTO prefers a valid Intel/DRM VAAPI render node while exposing an available NVIDIA runtime for capability testing.
- VAAPI render-node detection now supports hosts where the usable Intel device is not `renderD128`.
- Runtime profile detection prefers the valid device exposed by the running container over stale persisted device values.
- NVIDIA presence is separated from real NVENC capability: NVIDIA profiles are selectable only when an actual FFmpeg encoder self-test succeeds.
- Added separate WebAdmin status cards for VAAPI, NVIDIA and CPU backends.
- Added responsive layout for backend status cards.

## Intel VAAPI

- Added runtime-compatible H.264 VAAPI low-power/CQP operation for Intel generations requiring that encode path.
- Full VAAPI H.264 is preferred over encode-only VAAPI when the complete hardware decode/encode pipeline passes runtime validation.
- Encoder tuning cleanup removes conflicting rate-control options before applying the selected VAAPI profile.
- Direct Stream behaviour remains unchanged for compatible streams.

## Transcoding lifecycle

- Exposed the existing transcode GC lifecycle settings through Compose:
  - `STREMIOSRV_TRANSCODE_IDLE_TIMEOUT`
  - `STREMIOSRV_TRANSCODE_GC_INTERVAL`
  - `STREMIOSRV_TRANSCODE_GC_MAX_AGE`
- Preserved the normal per-job HLS lifecycle instead of introducing aggressive source-based deduplication.
- Abandoned FFmpeg jobs continue to be reclaimed by the existing idle reaper.
- Runtime tests confirmed abandoned jobs can be reclaimed without breaking repeat playback or seek behaviour.

## WebAdmin configuration reliability

- Registered the dedicated transcoding execution profile with the generic configuration model.
- Prevented generic configuration saves from overwriting profile-derived execution settings.
- Profile, hardware accelerator, VAAPI device, video codec and hardware-decode fields are managed through the verified transcoding profile workflow.
- Updated the expected streaming-server runtime version to 1.6.15.

## Validation

- Python 3.12 test suite: 1141 passed, 29 skipped.
- Focused transcoding/wrapper suite: 22 passed.
- Intel VAAPI validated on `/dev/dri/renderD129`.
- H.264 Full GPU VAAPI validated as the recommended execution profile.
- NVIDIA GeForce 920M runtime detection validated while NVENC remains unavailable and non-selectable after real encoder self-tests.
- HTTPS repeat playback, seek and abandoned-job cleanup validated.
