# Stremio Server WebAdmin 1.6.9-server.9

Package-only deployment release.

## Components

- Stremio core: `1.6.9`
- Fork/server integration: `1.6.9-server.9`
- WebAdmin: `1.2.7`
- Pi-hole: integrated through the Docker Compose stack

## Main change

The default `compose.yaml` no longer builds Server or WebAdmin from local source. A new installation pulls all application components from published container registries:

```text
ghcr.io/emmanique/stremio-libtorrent-server-webadmin:latest
ghcr.io/emmanique/stremio-libtorrent-server-webadmin-webadmin:latest
pihole/pihole:latest
```

This means a host needs Docker Compose and the deployment configuration, but does not need Python, uv or a local application build.

## Server update lifecycle

The WebAdmin server updater now pulls the immutable GHCR tag matching `SERVER_VERSION`, validates the image version label, preserves a rollback image, replaces only the Stremio container, waits for health validation and automatically restores the previous container if activation fails.

No Git archive download or local Docker build is required for a Server update.

## WebAdmin update lifecycle

WebAdmin is published independently as:

```bash
docker pull ghcr.io/emmanique/stremio-libtorrent-server-webadmin-webadmin:1.2.7
```

The stable alias is:

```bash
docker pull ghcr.io/emmanique/stremio-libtorrent-server-webadmin-webadmin:latest
```

WebAdmin updates are performed on the host with:

```bash
docker compose pull webadmin
docker compose up -d --no-deps webadmin
```

Persistent data is kept in Docker volumes and is not removed by image replacement.

## Full stack installation

Recommended managed installation:

```bash
git clone https://github.com/emmanique/stremio-libtorrent-server-webadmin.git
cd stremio-libtorrent-server-webadmin
sh start.sh
```

`start.sh` now performs an image pull followed by `docker compose up -d`; it does not build application images locally.

Minimal one-file installation:

```bash
mkdir -p stremio-platform
cd stremio-platform
curl -fsSLO https://raw.githubusercontent.com/emmanique/stremio-libtorrent-server-webadmin/main/compose.yaml
docker compose pull
docker compose up -d
```

## Preserved functionality

- Library / Cache Addon for Stremio
- poster and metadata recognition
- cache download, pin, unpin and delete operations
- trusted Stremio HTTPS endpoint integration
- automatic host IPv4 detection through `start.sh`
- Pi-hole integration and optional LAN DNS publication
- VAAPI and NVIDIA Compose overlays
- fork-owned upstream protection
- server transactional health validation and rollback
