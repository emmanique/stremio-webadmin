# Stremio Server WebAdmin 2.0.2

## Summary

Hotfix release focused on WebAdmin restart reliability and fresh-install hardening.

## Components

- Fork platform/server: 2.0.2
- WebAdmin: 2.0.2
- VPN gateway: 2.0.2

## Changes

- Prevent duplicate concurrent restart requests from the WebAdmin browser.
- Treat an existing restart operation as in progress instead of reporting a false failure.
- Route logging-mode restarts through the same coordinated restart path.
- Preserve the fresh-install IP/GPU detection and local configuration hardening already prepared on main.

## Validation

- CI
- Dependency validation
- Deterministic regression tests
- Network integration tests
- DIRECT save/restart runtime validation
- VPN save/restart runtime validation

## Upgrade notes

Preserve persistent Docker volumes. Do not use `docker compose down -v` during upgrade.
