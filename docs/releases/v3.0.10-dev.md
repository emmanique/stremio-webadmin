# Stremio Server WebAdmin 3.0.10-dev

## Status

Development consolidation baseline. This is **not a production release**.

## Summary

3.0.10-dev integrates Server/Core 1.6.27 under controlled upstream governance while preserving fork-owned behaviour in WebAdmin, VPN, Library, playback, subtitles and transcoding.

## Regression governance

- Functional regression is grouped by capability and versioned in the repository.
- Every new test must be assigned to at least one functional contract.
- A feature-specific test run is followed by the accumulated regression matrix.
- Local DEV and GitHub Actions execute the same regression scripts.
- Fork-owned Core paths are explicitly protected from automatic upstream replacement.
- DEV and production image publication are isolated.

## Components

- Fork platform: 3.0.10-dev
- WebAdmin: 3.0.10-dev
- Integrated Server/Core: 1.6.27

## Current functional contracts

Core/Torrent, Playback/Streaming, Transcoding, Subtitles, My Library/Continue Watching, VPN/Network, WebAdmin/Configuration, Version/Update and Packaging/Install.

## Promotion rule

This development baseline must not be published as a production release. Production promotion requires a stable version without the `-dev` suffix, complete regression, validated runtime tests and controlled promotion to `emmanique/stremio-webadmin`.

## Validation

Validation requires repository/static/compose gates, all functional regression contracts, deterministic and integration suites, image builds, runtime smoke tests and clean-install checks. Local functional and deterministic gates are passing; GitHub PR gates remain authoritative before consolidation.

## Upgrade notes

This is a development baseline and must not be used as a production upgrade target. Existing persistent configuration and volumes remain under regression validation before a stable 3.0.10 promotion.
