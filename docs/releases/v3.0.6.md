# Stremio Server WebAdmin 3.0.6

## Release architecture

Version 3.0.6 introduces the new public distribution architecture.

Development and validation are performed in the private development repository. Only validated stable releases are promoted to the public distribution repository.

Public source repository:

`https://github.com/emmanique/stremio-webadmin`

## Container images

Starting with 3.0.6, the official GHCR images use the simplified package names:

- Server: `ghcr.io/emmanique/stremio-server:3.0.6`
- WebAdmin: `ghcr.io/emmanique/stremio-webadmin:3.0.6`
- VPN: `ghcr.io/emmanique/stremio-vpn:3.0.6`

The `latest` tag identifies the latest validated public stable release.

## Release pipeline

The private release workflow is validation-only and cannot publish GHCR packages or GitHub releases.

The release process is:

Private development
→ CI
→ regression validation
→ DEV validation
→ private release tag
→ public promotion
→ public stable release
→ GHCR stable images.

## Compatibility

The Stremio Server core remains at version 1.6.22.

Existing 3.0.5 installations using the legacy GHCR package names remain valid and can continue to be used for rollback.

## Upgrade notes
New installations and upgrades from this release use:

`ghcr.io/emmanique/stremio-server`

`ghcr.io/emmanique/stremio-webadmin`

`ghcr.io/emmanique/stremio-vpn`

Runtime configuration, cache, library, VPN configuration and persistent WebAdmin settings remain stored in their existing persistent volumes.

## Summary


Version 3.0.6 introduces the separated development and public distribution model. Development, validation and release preparation are maintained in the private development repository, while the public `emmanique/stremio-webadmin` repository contains only validated stable source and public release tags.

This release also establishes the permanent GHCR package names `stremio-server`, `stremio-webadmin` and `stremio-vpn`. The `latest` tag is reserved for the latest validated public stable release.
