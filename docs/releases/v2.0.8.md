# Stremio Server WebAdmin v2.0.8

## Release summary

Version 2.0.8 is a runtime-stability and observability release built on the
2.0.7 live transcoding monitor. It keeps the integrated upstream server/core
at 1.6.15 while advancing the fork platform, WebAdmin and VPN gateway to 2.0.8.

## Configuration lifecycle

- Verify persisted configuration after a Stremio server restart.
- Report restart success only after the server is healthy and the saved
  configuration can be read back and verified.
- Preserve configuration in `/config/admin-settings.json`.
- Keep restart-required state explicit instead of silently assuming that
  configuration was applied.

## Transcoding and VAAPI

- Distinguish Requested, Effective and Actual runtime transcoding state.
- Detect active FFmpeg processes and expose PID, CPU, memory and elapsed time.
- Correlate active processes with their transcoding job logs.
- Preserve the active `ffmpeg-policy` record even when it falls outside the
  last log lines used for progress telemetry.
- Parse profile-aware policy records such as `vaapi-full-h264`.
- Automatically verify hardware profiles when WebAdmin starts with an empty
  capability cache.
- Expose verified H.264/HEVC VAAPI capability and full-GPU profile readiness.
- Validate `vaapi-full-h264` hardware decode and H.264 VAAPI encode execution.

## VPN, DNS and certificates

- Validate Stremio local health during VPN connect, disconnect and reconnect.
- Keep the persistent Gluetun gateway architecture in both DIRECT and VPN
  operating states.
- Harden DIRECT-mode DNS forwarding through Pi-hole and the gateway DNS proxy.
- Prevent replacement of a valid trusted certificate with an empty or failed
  certificate download.

## Validation

The 2.0.8 stabilization work was validated with:

- configuration save, restart and read-back verification;
- fresh-process VAAPI capability detection;
- real HEVC to H.264 VAAPI Full GPU transcoding;
- live FFmpeg PID and resource telemetry;
- profile-aware policy telemetry;
- DNS and trusted-certificate validation;
- deterministic regression tests under Python 3.12.

Persistent Docker volumes must be preserved during upgrade. Do not use
`docker compose down -v`.
