# Stremio Server WebAdmin v2.0.6

## Release summary

This release hardens the Gluetun network namespace lifecycle during unified Compose upgrades.

## Changes

- Detect when Stremio still references a stale Gluetun container namespace after the gateway container is recreated.
- Recreate only `stremio-libtorrent-server` when namespace repair is required.
- Leave Stremio untouched when it already references the current Gluetun container ID.
- Reuse the active Compose configuration and automatic VAAPI/GPU overlay selection during repair.
- Verify the repaired `container:<gluetun-id>` relationship and fail closed if it is still incorrect.
- Avoid unnecessary Pi-hole and WebAdmin recreation during the namespace repair.
- Add regression coverage for both stale-namespace repair and the already-correct no-op path.

## Versions

- Server: 1.6.15
- Fork: 2.0.6
- WebAdmin: 2.0.6

## Upgrade safety

Persistent Docker volumes and WebAdmin configuration are unchanged. The base hardware-agnostic Compose definition remains unchanged.

Validated by repository CI before and after merge. Release publication additionally runs the release contract, dependency, deterministic, network integration, Compose, image build, smoke, registry publication, anonymous-pull, and GitHub Release stages.
