# Stremio Server WebAdmin v2.0.7

## Release summary

This release introduces the new WebAdmin live transcoding monitor and prepares the observability layer required for future adaptive client-aware transcoding.

## Changes

- Correlate active FFmpeg processes with their individual transcode job directories instead of relying only on the most recently modified log.
- Show every active FFmpeg session independently.
- Display Direct Stream vs Transcoding for each session.
- Display source and target video/audio codecs.
- Display the active execution engine: copy, VAAPI, NVENC or CPU.
- Display FFmpeg PID and elapsed process time.
- Display per-process CPU and memory utilization.
- Display per-session FFmpeg progress, FPS and speed.
- Display the wrapper policy decision associated with each active job.
- Recover source codec information from the job FFmpeg log when the policy line does not explicitly expose it.
- Keep the existing hardware capability cards and verified execution profiles.

## Compatibility

The monitor is read-only. It does not change the v2.0.6 transcoding policy, VPN routing, Gluetun namespace lifecycle, configuration persistence, Pi-hole DNS chain or VAAPI device configuration.
