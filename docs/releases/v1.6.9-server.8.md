# Stremio Server WebAdmin 1.6.9-server.8

First stable release of the consolidated fork release lifecycle.

## Components

- Stremio core: `1.6.9`
- Fork/server integration: `1.6.9-server.8`
- WebAdmin: `1.2.6`
- Pi-hole: integrated through the Docker Compose stack

## Included

- Self-hosted Stremio libtorrent runtime
- Independent WebAdmin service
- Pi-hole integration and optional LAN DNS publishing
- Library / Cache Addon for Stremio
- Poster and metadata recognition for cached movies and series
- Library management with download, pin, unpin and delete operations
- WebAdmin addon discovery, installation URL and addon update controls
- Automatic host IPv4 detection through `start.sh`
- VAAPI and NVIDIA runtime overlays
- Fork-owned update lifecycle and upstream-protection guardrails
- Transactional WebAdmin/server update checks and rollback guardrails

## First GitHub Package

The server runtime is published to GitHub Container Registry as:

```bash
docker pull ghcr.io/emmanique/stremio-libtorrent-server-webadmin:1.6.9-server.8
```

The stable alias is also available as:

```bash
docker pull ghcr.io/emmanique/stremio-libtorrent-server-webadmin:latest
```

To use the published runtime with the repository's package-oriented compose file:

```bash
STREMIO_IMAGE=ghcr.io/emmanique/stremio-libtorrent-server-webadmin:1.6.9-server.8 \
  docker compose -f compose.hub.yaml up -d
```

For the complete WebAdmin + Pi-hole stack, clone the repository and use the normal launcher:

```bash
git clone https://github.com/emmanique/stremio-libtorrent-server-webadmin.git
cd stremio-libtorrent-server-webadmin
sh start.sh
```

## Release policy

Development is performed on the permanent `future` branch. A version is promoted to `main` only after the repository validation gates pass. Release tags and container packages are created from `main`.
