# Stremio Server WebAdmin 2.0.1

## Summary

Version 2.0.1 is a maintenance and reliability release for the unified 2.x runtime. It incorporates the latest upstream library corrections while preserving the fork-specific playback, VPN and configuration lifecycle protections.

## Components

- Fork platform/server: 2.0.1
- WebAdmin: 2.0.1
- VPN gateway: 2.0.1

## Main changes

- Integrated upstream Stremio library changes through upstream commit `806dde906c68d94d7abf61e9c2ee9a6348d1f8ea`.
- Improved single-video torrent label fallback and resume-file handling.
- Prevented codec/audio strings such as `DD5.1x264` from being interpreted incorrectly as episode identifiers.
- Preserved fork-specific multi-file, episode and playback selection rules.
- Fixed Docker startup when the Stremio container shares Gluetun's network namespace.
- Removed the incompatible Stremio hostname declaration when using `network_mode: service:gluetun`.
- Added CI protection against reintroducing the shared-network namespace conflict.
- Normalized the Windows `start.bat` launcher in Git while preserving CRLF checkout behavior on Windows.

## Validation

- 139 library/upstream regression tests passed.
- 18 VPN, configuration and WebAdmin regression tests passed.
- `compose.yaml` validation passed.
- Shared Gluetun network namespace contract validated.
- DIRECT mode Save Configuration and Restart Server validated.
- VPN mode Save Configuration and Restart Server validated.
- DIRECT -> VPN -> DIRECT transition validated without recreating the stack.
- Persistent configuration validated across container and stack restarts.
- TCP and UDP port 6881 publication validated through the Gluetun namespace.
- The release workflow will additionally run the complete deterministic and network integration gates, Compose variants, image builds and smoke tests before publication.

## Upgrade notes

Existing 2.0.0 installations can upgrade without recreating persistent volumes.

Preserve the existing Docker volumes. Do not use `docker compose down -v` during the upgrade.

VPN configuration and Stremio configuration remain persistent across the upgrade.
