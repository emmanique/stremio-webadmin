# Stremio Server WebAdmin 2.0.12

Runtime-reliability hotfix validated from the 2.0.11 test-server regressions.

## Fixed

- VAAPI Full GPU playback no longer assumes every real HEVC/H.264 profile supported by the synthetic self-test is safe for hardware decode.
- High-bit-depth sources such as HEVC Main 10 can fall back to software decode while keeping VAAPI hardware encode.
- The recommended Intel/DRM execution profile now prefers `vaapi-h264` over `vaapi-full-h264` when both are available.
- Transcoding Requested/Effective telemetry is aligned with the explicit execution profile.
- WebAdmin **Clean selected** and **Clean all** now cover Application, Docker container, updater and admin logs. Docker-owned logs use persistent clear cursors rather than unsafe log-file truncation.
- WebAdmin reloads committed configuration after save and after a validated server restart.
- My Library per-file playback controls now display an explicit **Watch** action.

## Upgrade

```bash
cd ~/stremio-libtorrent-server-webadmin
git fetch --prune origin
git checkout main
git pull --ff-only origin main
docker compose pull
sh start.sh
```

Do not use `docker compose down -v`; the named volumes contain persistent configuration, cache, Pi-hole and VPN data.
