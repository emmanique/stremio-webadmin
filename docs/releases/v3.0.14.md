# Stremio Server WebAdmin 3.0.14

## Summary

Stabilizes Proton VPN dynamic inbound port forwarding for WireGuard and OpenVPN. The gateway now revalidates TCP and UDP firewall rules after tunnel reconnection and removes obsolete rules and leases after disconnect. BitTorrent listens on the provider-assigned NAT-PMP port. CyberGhost connections remain supported without claiming unavailable provider port forwarding.

## Components

- Platform / WebAdmin / VPN gateway: **3.0.14**
- Integrated Core: **1.6.34**
- Default DIRECT BitTorrent port: **6881**
- Proton VPN: WireGuard, OpenVPN UDP and OpenVPN TCP
- Dynamic port forwarding: NAT-PMP, confirmed TCP/UDP mappings, tun0-scoped rules

## Validation

- DEV CI, Functional Regression, DEV Images and VPN firewall/health regression passed for the preceding 3.0.14-dev baseline.
- Live VPN validation on 192.168.1.244: Proton WireGuard, OpenVPN UDP and TCP established tunnels and matched NAT-PMP listen ports and firewall rules.
- Verified exclusive VPN profile activation, CyberGhost OpenVPN without Proton port mapping, loss of VPN outbound connectivity under test DROP rule, gateway container restart recovery, and eventual cleanup of forwarded-port rules on disconnect.
- Deployment candidate must pass the stable-release workflow independently before promotion.
- Scope limitations: external Internet peer reachability of forwarded ports, device-side DNS/DoH leak capture, end-to-end long-playback position and SRT checks, and a full host reboot have not been demonstrated. Do not represent these as PASS.

## Upgrade notes

Preserve the persistent volumes and VPN profiles. Use matching 3.0.14 Server, WebAdmin and VPN images; never mix a 3.0.14 VPN supervisor with an older Core for final validation. The existing 5 GiB cache configuration remains an operator setting, not a global default. Upgrade only after backups and a verified health-based rollback route. DIRECT is an intentional no-VPN mode and exposes the host's normal public address. The public repository must not contain GitHub Actions workflows.
