SOFTWARE UPDATES
Manual upgrade only.
Follow the release/README procedure: back up persistent configuration, replace the deployment package, run scripts/check-env-upgrade.sh, then validate with sh start.sh config, sh start.sh pull and sh start.sh up -d --force-recreate. Preserve .env and named Docker volumes; never use docker compose down -v for a routine upgrade.
Version and status information is loaded when the WebAdmin page opens.
Upgrade instructions are informational; WebAdmin does not start upgrades automatically.
