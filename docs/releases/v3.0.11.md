# Stremio Server WebAdmin 3.0.11

## Summary

Release 3.0.11 consolidates the upstream Core 1.6.34 integration and hardens runtime lifecycle and storage accounting.

## Highlights

- Aligns the bundled/target Stremio Core with **1.6.34** while preserving the fork's AUTO transcoding, resume, Library and WebAdmin enhancements.
- Fixes FFmpeg process lifecycle cleanup so terminated or killed transcode jobs are fully reaped and stale jobs are removed from bookkeeping.
- Protects Core certificate metadata (`cert-status.json`) from media-cache listing and eviction.
- Treats transcoding output as reserved cache capacity: **reserved = media cache + transcode output**.
- Uses reserved capacity in cache headroom, eviction decisions and Pin disk-space admission without making active transcode output evictable.
- Clarifies WebAdmin storage labels by separating cache limit/free, media usage, transcode reservation and physical disk free space.
- Aligns runtime target defaults, Quick Start and stable-release validation with Core **1.6.34**.

## Upgrade notes

Existing persistent configuration and media volumes remain compatible. The configured cache limit now accounts for both managed media cache and transcode output when calculating reserved/free cache capacity. Physical disk free space remains an independent safety constraint.
