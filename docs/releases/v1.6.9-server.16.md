# Stremio Server WebAdmin 1.6.9-server.16

## Components

- Core: `1.6.9`
- Server/Fork: `1.6.9-server.16`
- WebAdmin: `1.4.0`
- VPN gateway: `1.6.9-server.16`

## New: dedicated Gluetun management page

This release adds a dedicated **WebAdmin -> Gluetun** operational page, separate from the CyberGhost VPN profile manager.

### Gateway status

The page exposes non-secret runtime information for the Gluetun gateway:

- container state and Docker health;
- VPN tunnel status and public IP;
- active VPN profile;
- uptime and restart count;
- CPU and memory usage;
- received and transmitted bytes;
- Gluetun DNS and updater state;
- Docker network addresses.

### Gateway actions

The WebAdmin can start, stop and restart the Gluetun container and run an end-to-end validation of the VPN path. Stopping the gateway remains fail-closed: Stremio must not fall back to the host WAN.

### Configuration visibility

The page shows the effective non-secret gateway configuration, including VPN mode/type, firewall and kill-switch state, allowed LAN CIDRs, DNS settings, private Pi-hole DNS proxy, health targets and timezone.

Security-critical values remain protected and are never returned to the browser, including OpenVPN credentials, private keys, certificates as editable secrets and the Gluetun control API key.

### Network and health validation

The validation view checks:

- Gluetun container running;
- Docker health;
- Gluetun control API;
- VPN tunnel;
- DNS service;
- private DNS proxy;
- Pi-hole upstream path;
- Stremio routing through Gluetun;
- kill-switch state.

### Gluetun logs

The new viewer supports selectable line count, level filtering, free-text search, manual or automatic refresh and local viewer clearing. Sensitive VPN values are redacted server-side.

## WebAdmin layout

The WebAdmin menu now includes a dedicated Gluetun section alongside the VPN profile manager:

```text
Dashboard | Server | Transcoding | VPN | Gluetun | Logs
```

The **VPN** page remains responsible for CyberGhost profile import, credentials and profile lifecycle. The **Gluetun** page is responsible for gateway runtime status, operational actions, effective configuration, network validation and logs.
