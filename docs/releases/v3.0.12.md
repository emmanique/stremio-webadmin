# Stremio Server WebAdmin 3.0.12

## Automatic BitTorrent listen port

- `Bt Listen Port` is now read-only in WebAdmin and reports the effective runtime listener.
- DIRECT mode and VPN providers without port forwarding safely use the default `6881`.
- The Core can follow a provider-assigned forwarded port live through `/vpn/forwarded_port`, without restarting the Stremio server.
- Invalid or missing provider state falls back safely to the default listener.
- `/netcheck.json` reports `listenPortMode` and `configuredDefaultPort` for diagnostics.
- VPN supervisor clears stale forwarded-port state on DIRECT transitions and profile changes.
- CyberGhost remains correctly identified as a provider without VPN port forwarding; outbound P2P is unchanged.

## Compatibility

- Platform/WebAdmin: 3.0.12
- Core: 1.6.34
- Default BitTorrent listen port: 6881
- Existing VPN, DNS/Pi-hole, cache, transcoding, Continue Watching and Library behaviour is preserved.

## Upgrade

Use the normal documented upgrade procedure. Persistent configuration and volumes are preserved. The BitTorrent listen port no longer requires manual editing in WebAdmin.
