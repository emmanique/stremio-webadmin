# Stremio Server WebAdmin 2.0.11

Release 2.0.11 adds native Stremio player hand-off from My Library while keeping upstream server/core at 1.6.15.

## My Library playback

- Adds **Watch** controls for playable cached and downloaded titles.
- Adds per-file play controls for multi-file torrents and season packs when the torrent file index is known.
- Delegates playback to the bundled Stremio Web player using the canonical encoded torrent Stream deep-link.
- Preserves the standard Stremio player audio-track selector, subtitle selector, torrent traffic/statistics panel, casting controls, and existing direct-stream/transcoding policy.
- Leaves `fileIdx` unset when a single media file cannot be identified so the streaming server can apply its normal media-file selection.
- Excludes orphaned part files from playback actions.

## Upgrade

From an existing installation:

```bash
cd ~/stremio-libtorrent-server-webadmin
git pull --ff-only
sh start.sh
```

After the release workflow publishes the images, the same launcher pulls the current published images and recreates only what is required by the active Compose configuration.
