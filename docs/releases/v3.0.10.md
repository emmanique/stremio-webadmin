# Stremio Server WebAdmin 3.0.10

## Status

Stable production release candidate after completed regression and runtime validation.

## Summary

3.0.10 integrates Server/Core 1.6.27 under controlled upstream governance while preserving fork-owned behaviour in WebAdmin, VPN, Library, playback, subtitles and transcoding.
\nKey playback fixes in this release:

- Continue Watching now uses the immutable source duration during growing HLS EVENT transcoding.
- Resume time is preserved across Web Player and Stremio App playback without cumulative HLS offset drift.
- Firefox retries autoplay after the HLS manifest is parsed.
- Web Player cache/service-worker revisioning prevents stale runtime-patched `main.js` after upgrades.
- My Library player links preserve complete Core playback identity when factual stream/meta context is available.

## Regression governance

- Functional regression is grouped by capability and versioned in the repository.
- Every new test must be assigned to at least one functional contract.
- A feature-specific test run is followed by the accumulated regression matrix.
- Local DEV and GitHub Actions execute the same regression scripts.
- Fork-owned Core paths are explicitly protected from automatic upstream replacement.
- DEV and production image publication are isolated.

## Components

- Fork platform: 3.0.10
- WebAdmin: 3.0.10
- Integrated Server/Core: 1.6.27

## Current functional contracts

Core/Torrent, Playback/Streaming, Transcoding, Subtitles, My Library/Continue Watching, VPN/Network, WebAdmin/Configuration, Version/Update and Packaging/Install.

## Promotion rule

Production promotion requires complete regression, validated runtime tests and controlled promotion to `emmanique/stremio-webadmin`.

## Validation

Validation requires repository/static/compose gates, all functional regression contracts, deterministic and integration suites, image builds, runtime smoke tests and clean-install checks. Local regression and runtime smoke gates pass for the release candidate; repository CI remains the publication gate.

## Upgrade notes

Preserve existing persistent configuration and volumes during upgrade. Validate `.env` additions before deployment.
- Existing installations should review `STREMIOSRV_HOST_MIN_FREE_GB` and `STREMIOSRV_HOST_MIN_FREE_PERCENT`; defaults are 10 GiB and 10% when omitted.
