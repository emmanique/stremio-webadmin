# Stremio Server WebAdmin 1.6.9-server.10

## Components

- Core: `1.6.9`
- Server/Fork: `1.6.9-server.10`
- WebAdmin: `1.3.0`
- VPN gateway: `1.6.9-server.10` (Gluetun-based CyberGhost integration)

## Highlights

### CyberGhost VPN in WebAdmin

A new **VPN** page manages the Stremio VPN gateway from the browser:

- CyberGhost OpenVPN configuration;
- UDP/TCP selection;
- optional country/hostname filters;
- saved-credential state without returning secret values;
- client certificate/private-key storage in the private `vpn-data` volume;
- Connect / Disconnect / Reconnect controls;
- VPN public IP and tunnel status;
- kill-switch and routing state;
- RX/TX counters;
- protection test comparing host, VPN and Stremio egress;
- redacted Gluetun logs.

### Fail-closed VPN architecture

`compose.vpn.yaml` is now a complete Server + WebAdmin + Pi-hole deployment. Only Stremio shares Gluetun's network namespace. WebAdmin and Pi-hole remain directly reachable on the LAN.

Disconnecting the VPN intentionally blocks Stremio Internet traffic rather than falling back to the normal host WAN.

### Dedicated VPN package

This release publishes a third public GHCR package:

```text
ghcr.io/emmanique/stremio-libtorrent-server-webadmin-vpn:1.6.9-server.10
```

The gateway is based on a pinned Gluetun release and reads CyberGhost material from the private VPN configuration volume at container start.

### VPN launcher

`start-vpn.sh` detects the current LAN address, generates a private Gluetun control API key on first use, pulls published images and starts the VPN stack.

Switch back to direct mode with:

```bash
sh start.sh
```

Persistent Server, WebAdmin, Pi-hole and VPN configuration volumes are retained.

## CyberGhost note

CyberGhost manual OpenVPN uses generated OpenVPN credentials plus the user certificate/private key. CyberGhost does not provide VPN-side port forwarding, so VPN mode deliberately does not publish the Stremio BitTorrent listen port on the host. Outbound P2P remains available.

See [`VPN.md`](../../VPN.md) for setup and verification steps.
