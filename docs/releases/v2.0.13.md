# Stremio Server WebAdmin 2.0.13

HLS media-track hotfix for the native Stremio player hand-off introduced in 2.0.11 and validated on the 2.0.12 runtime baseline.

## Fixed

- Transcoded HLS now preserves multiple audio renditions instead of mapping only `0:a:0`.
- Alternate audio tracks are exposed through an HLS audio group so the native player can enable its audio selector.
- Text subtitle tracks are converted to WebVTT and exposed through an HLS subtitle group.
- Bitmap subtitle formats such as PGS/DVD/DVB are excluded from WebVTT conversion so they cannot abort an otherwise valid playback job.
- Multi-track presentations normalise audio to AAC stereo for browser compatibility while leaving the existing single-track path unchanged.
- HLS serving reports appropriate media types for MPEG-TS and WebVTT artefacts.
- The validated 2.0.12 VAAPI path remains unchanged: HEVC Main 10 can use software decode plus `h264_vaapi` encode.

## Validation target

Use a multi-track MKV and confirm that the Stremio player exposes selectable audio and subtitle controls while transcoding through the selected verified execution profile.

## Upgrade

```bash
cd ~/stremio-libtorrent-server-webadmin
git fetch --prune origin
git checkout main
git pull --ff-only origin main
docker compose pull
sh start.sh
```

Do not use `docker compose down -v`; the named volumes contain persistent configuration, cache, Pi-hole and VPN data.
