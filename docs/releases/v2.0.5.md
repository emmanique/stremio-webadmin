# Stremio Server WebAdmin v2.0.5

## Release summary

This release fixes Direct Stream codec policy when an explicit transcoding profile is selected, with particular focus on VAAPI deployments.

## Changes

- Preserve H.264 video copy when H.264 is allowed by the configured Direct Stream video codec list.
- Route incompatible copied video, such as HEVC when only H.264 is allowed for Direct Stream, through the selected transcoding profile.
- Support VAAPI HEVC decode to H.264 VAAPI encode with the `vaapi-full-h264` profile.
- Probe the source video codec with ffprobe before deciding whether copied video is Direct Stream compatible.
- Preserve video copy as a fail-safe when source codec probing is unavailable or fails.
- Keep legacy copy/passthrough behavior unchanged when no explicit transcoding profile is selected.
- Add regression coverage for H.264 Direct Stream, HEVC-to-VAAPI transcoding, probe failure, HEVC Direct Stream allowance, and legacy copy mode.
