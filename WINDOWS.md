# Windows quick start

Native Windows launchers are included for Docker Desktop:

```text
start.bat       -> start.ps1       -> direct mode
start-vpn.bat   -> start-vpn.ps1   -> VPN/Gluetun mode
```

For installation requirements, Docker Desktop/WSL2 notes, IP overrides, Docker Hub examples, GPU/transcoding guidance and troubleshooting, see [`docs/WINDOWS.md`](docs/WINDOWS.md).

Quick start from Command Prompt:

```bat
start.bat
```

VPN mode:

```bat
start-vpn.bat
```

Quick start from PowerShell:

```powershell
.\start.ps1
.\start-vpn.ps1
```
