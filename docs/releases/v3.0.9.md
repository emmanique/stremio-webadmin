# Stremio Server WebAdmin 3.0.9

## Summary

3.0.9 improves HEVC Main10/HDR playback on validated Intel/iHD VAAPI systems and makes
embedded-subtitle discovery more reliable while a torrent is still incomplete.

- HEVC Main10 is no longer categorically forced to software decode. The AUTO policy may use
  full VAAPI decode, HDR-to-SDR tone mapping and H.264 VAAPI encode when runtime self-tests
  confirm that path.
- High-bit-depth H.264 and HEVC formats above the validated Main10 path retain the conservative
  software-decode fallback.
- The guarded local-media head sniff now uses the normal torrent reader, which actively boosts
  the required head piece instead of passively waiting for it. This reduces false
  `media source head unavailable` failures during HLS and embedded-subtitle probing.
- Existing 3.0.8 Web Player persistence, disk reserve, Library, VPN, cache and transcoding
  behaviour is retained.

## Validation

Development validation on the Ubuntu 24.04 / Intel Iris Xe iHD VAAPI test host includes:

- focused policy, media-fetch, transcode-dedup and HDR tests;
- runtime probe of a 2160p HDR10+ HEVC Main10 MKV;
- full GPU pipeline observed with VAAPI decode, `tonemap_vaapi` and H.264 VAAPI encode;
- incomplete-torrent real-time HLS observed at approximately 1.0x with low CPU utilisation;
- embedded SubRip tracks discovered in the HLS master and through `subtitles.json`;
- finite WebVTT extraction validated with real subtitle cues;
- full regression passed: 1463 non-integration tests passed, 11 skipped and 10 deselected,
  followed by the integration suite and release image/package validation;
- deployment ZIP/TAR.GZ packages were built and their SHA-256 checks verified.

## Upgrade notes

No new or removed environment variables and no persistent-state migration are required.
Existing `.env`, Stremio configuration, cache, WebAdmin state, VPN state and Pi-hole volumes
remain compatible. Upgrade using the normal release procedure and published 3.0.9 Server and
WebAdmin images.
